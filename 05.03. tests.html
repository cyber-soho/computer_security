Flash-cards — 25 cards, click to flip

Each card asks one of the questions a professor would ask in the Class 8 flash-card blitz. Say the answer out loud before flipping.

Lesson 1Which two questions separate a virus from a worm?
answerSelf-replication (both say yes) and host dependency: a virus needs a host file and a user who runs it; a worm is stand-alone and spreads by itself through a network service or weak passwords.
Lesson 1What is a payload?
answerThe part of the malware that performs the intended damage — encrypt, steal, control, hide, destroy — as opposed to the part that spreads or hides it.
Lesson 1What does a rootkit change, and what follows for removal?
answerThe operating system itself (kernel modules, drivers, libraries, sometimes firmware), to hide other malware. The running OS cannot be trusted; detection needs an offline scan and removal means rebuilding from known-good media.
Lesson 1What is beaconing?
answerThe regular connection a bot makes to its command-and-control server to fetch orders; a connection every 60 seconds to the same unknown address is a typical sign.
Lesson 1Why is a logic bomb usually an insider's tool?
answerIt waits for a condition (a date, an account removed from payroll) and is planted by someone with legitimate access; it neither replicates nor arrives from outside, so access control and code review are the defences.
Lesson 2What is an infection vector?
answerThe path by which malware reaches a computer and is executed for the first time: e-mail attachments and macros, drive-by downloads, removable media, supply-chain compromise, exposed services with weak credentials.
Lesson 2What is a dropper (loader)?
answerA small first-stage program, often a macro, whose only job is to download and start the real malware.
Lesson 2What is the Mark of the Web and what does it change?
answerA flag attached to files that came from the Internet; Office blocks macros in flagged files, which is why attackers moved to archives, disc images and shortcut files.
Lesson 2Name four Windows persistence locations.
answerRegistry Run keys, the Startup folder, scheduled tasks, services (plus WMI event subscriptions); Autoruns lists them all.
Lesson 2What is living off the land?
answerUsing programs already on the machine and signed by the vendor — PowerShell, certutil, mshta — so that no new executable exists for a scanner to detect.
Lesson 3What is the reference monitor?
answerThe part of the operating system that decides, for every request, whether this process acting for this user may access that resource.
Lesson 3Decode -rwxr-x--- and give its octal value.
answerA regular file; owner read-write-execute (7), group read-execute (5), others nothing (0): mode 750.
Lesson 3What is the Windows equivalent of a 777 folder?
answerA shared folder with Everyone: Full control (NTFS ACL); both let any account write anywhere in the folder.
Lesson 3What does Event ID 4625 mean, and what is its Linux equivalent?
answerA failed logon in the Windows Security log; on Linux a 'Failed password for … from …' line in /var/log/auth.log or the journal. A burst from one address is password guessing.
Lesson 3Why did WannaCry succeed?
answerIt exploited a vulnerability in SMB version 1 that Microsoft had patched two months earlier; every victim had not installed the update — patching is the control.
Lesson 4What is the first step of the standard response, and what must you not do?
answerIsolate: disconnect from the network, keep the machine powered on. Do not power it off — volatile memory holds evidence and some families react to a shutdown.
Lesson 4What do you establish in the 'identify' step?
answerThe family, the hosts involved, the time, and the vector — from the AV/EDR console, the note, file names, the Security log (4625, 4720, 7045), the auth log and the mail gateway.
Lesson 4Give three containment actions.
answerDisable compromised accounts and change the shared administrator password from a clean machine; block the C2 address at the firewall; take shares offline; preserve evidence (copy note, sample, logs to labelled media).
Lesson 4Why is 'wipe and reinstall' the eradication method for rootkits and ransomware?
answerA compromised operating system cannot be trusted to report its own state; cleaning in place is unreliable, rebuilding from known-good media is not.
Lesson 4Why not pay the ransom in the first hour?
answerNo guarantee of a working key, it funds further crime, it may breach sanctions rules, and the stolen copy of the data remains with the attacker; the decision belongs to management after containment.
Lesson 5What is hardening?
answerConfiguring a system to expose the smallest possible attack surface: remove or disable what is not needed, restrict what remains, record the result as a baseline.
Lesson 5What are the CIS Benchmarks?
answerConsensus, step-by-step secure-configuration guides published by the Center for Internet Security for operating systems, browsers, databases and cloud services.
Lesson 5Signature-based versus behavioural detection?
answerSignatures match known patterns and hashes (fast, blind to new or packed samples); behavioural detection stops a program by what it does (mass encryption), at the price of some false positives.
Lesson 5What does EDR add to antivirus?
answerA recorded history of process, file, registry and network events on every endpoint, correlation into detections, and remote isolation from a console.
Lesson 5State the 3-2-1 rule and the modern addition.
answerThree copies, two media types, one off-site — and that copy off-line or immutable, because ransomware looks for backups; test the restore.
