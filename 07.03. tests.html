Flashcards — tap any card to flip

25 cards across the five lessons. Recognise the prompt, say the answer, then flip to check.

card 1/25Plaintext vs ciphertext vs key — in one line each.
Plaintext: the readable message. Ciphertext: the transformed, unreadable message. Key: the secret value that controls encryption and decryption.
card 2/25Why is encoding (Base64) not encryption?
Encoding changes the representation of data for transport and uses no secret, so anyone can reverse it — it gives no confidentiality.
card 3/25What makes the Caesar cipher trivial to break?
It has only 25 useful keys, so an attacker simply tries all of them (brute force) and reads the one result that is English.
card 4/25Why does a repeating keyword (Vigenère) not give lasting security?
The key length can be found (Kasiski), after which each column has a single shift and falls to frequency analysis.
card 5/25State Kerckhoffs's principle in your own words.
A system must stay secure even if the algorithm is public; only the key is secret. So use standard published algorithms and never invent your own.
card 6/25Why does each added key bit matter so much?
Each bit doubles the number of possible keys (2^n), so it doubles the brute-force cost; adding bits is how you outrun brute force.
card 7/25Name the three properties of a cryptographic hash.
Pre-image resistance (cannot invert), second-pre-image resistance (cannot match a given input), collision resistance (cannot find any two inputs with the same digest).
card 8/25What is a salt and what attack does it defeat?
A unique random value stored with each password hash; it makes identical passwords hash differently and defeats precomputed rainbow tables.
card 9/25Why must a password-hashing function be slow?
So that an attacker with a stolen database cannot try billions of guesses per second; Argon2/bcrypt are tuneably slow.
card 10/25What does HMAC give that encryption does not?
Integrity and authenticity: a keyed tag proving a message was not altered and came from a holder of the shared key.
card 11/25How does a public/private key pair solve key sharing?
Anyone encrypts to you with your public key; only your private key decrypts — so no secret has to be shared in advance.
card 12/25Why is RSA hard to break?
Its security rests on the difficulty of factoring a large number back into the two primes that were multiplied to make it.
card 13/25What does ephemeral Diffie-Hellman (ECDHE) add?
Forward secrecy: a fresh per-session key means a later theft of the long-term key cannot decrypt past sessions.
card 14/25How is a digital signature made and checked?
Hash the message, transform the digest with the private key (that is the signature); anyone verifies it against the message with the public key.
card 15/25What does the browser padlock actually mean?
A trusted certificate authority has vouched for the site's public key, the certificate's name matches and it is unexpired, and a session key protects the data.
card 16/25Give one example of each authentication factor.
Knowledge: a password. Possession: a phone or security key. Inherence: a fingerprint or face scan.
card 17/25Why is 'password + security question' not real MFA?
Both are knowledge factors; true MFA needs two different factors, so one phished secret does not give the attacker both.
card 18/25How does a TOTP authenticator code work?
The app and server share a secret; each computes an HMAC of the current 30-second time-step and takes a few digits, so both show the same code.
card 19/25Why is a passkey phishing-resistant?
Its signature is bound to the real site's address and useless on a look-alike page, and the server stores only a public key — nothing to phish, steal or reuse.
card 20/25In Kerberos, what is a Ticket-Granting Ticket?
A time-limited pass you receive after one login; you present it to the KDC to get short-lived service tickets, so services never see your password.
card 21/25List the five steps of the TLS handshake.
Hello (cipher list); server certificate; verify the chain/name/date; agree a fresh key by ECDHE; switch to AES with a MAC.
card 22/25Name the stages of the key lifecycle.
Generation (CSPRNG), distribution, storage (HSM for high-value keys), rotation, and revocation/destruction.
card 23/25What does a VPN protect, and what does it not?
It encrypts traffic in transit through its tunnel; it does not protect a compromised endpoint, a weak password behind it, or malware inside — and it should require MFA.
card 24/25Why do short-lived certificates renew automatically?
Short lifetimes make manual renewal error-prone, so the ACME protocol renews them by software, avoiding an expired certificate taking the site offline.
card 25/25What is 'harvest now, decrypt later'?
Recording encrypted traffic today to decrypt it once quantum computers exist — which is why long-lived secrets need post-quantum protection now.

Practice test

FORMATIVE practice — not summative and never counted toward your grade. 15 multiple-choice and 10 multiple-select questions; each MSQ says how many answers to pick.

1. A BlueFern developer encrypts NIGHT with a Caesar shift of 5. What is the ciphertext? MCQ (one answer) L1 · Classical ciphers

Hint: N=13,I=8,G=6,H=7,T=19; add 5 to each, modulo 26.
Answer & why: (a) Correct: N(13)→18=S, I(8)→13=N, G(6)→11=L, H(7)→12=M, T(19)→24=Y → SNLMY. The others mis-add or mishandle a wrap.

2. An analyst counts the letters in a captured message and finds one symbol far more common than the rest, matching English's letter frequencies. Which cipher was most likely used? MCQ (one answer) L1 · Classical ciphers

Hint: Which cipher preserves the plaintext's letter frequencies?
Answer & why: (a) Correct: a substitution cipher keeps each letter's frequency, so the counts betray it. A one-time pad and AES produce flat, random-looking output; ECDHE is not a cipher for messages.

3. Why is 'we keep our encryption method secret so no one can break it' a poor security strategy? MCQ (one answer) L1 · Classical ciphers

Hint: Kerckhoffs's principle: where should the secret live?
Answer & why: (a) Correct: methods leak, and you cannot change a method the way you change a key; security must rest on the key alone.

4. Two BlueFern staff both choose the password Autumn2026. With which storage scheme would their stored values be IDENTICAL? MCQ (one answer) L2 · Symmetric & hashing

Hint: Identical values appear only when nothing unique is mixed in before hashing.
Answer & why: (a) Correct: with no salt, the same password gives the same digest, which an attacker spots immediately. A unique salt (bcrypt, Argon2id) makes them differ.

5. A key is lengthened from 80 bits to 88 bits. Roughly how much harder is a brute-force search now? MCQ (one answer) L2 · Symmetric & hashing

Hint: 8 extra bits; each bit doubles the work.
Answer & why: (a) Correct: 2^8 = 256. (b) 8 would be 3 extra bits. (c) confuses key length with the factor. (d) more bits always multiply the cost.

6. BlueFern wants to prove an order file was not tampered with and came from a system that holds the shared key. Which is the right tool? MCQ (one answer) L2 · Symmetric & hashing

Hint: You need integrity + authenticity with a shared key.
Answer & why: (a) Correct: an HMAC is a keyed tag. Base64 is not security; AES alone does not by itself prove the sender or detect all tampering; a keyless hash can be recomputed by anyone who alters the file.

7. Why is storing passwords 'encrypted with AES' the wrong choice? MCQ (one answer) L2 · Symmetric & hashing

Hint: What can be done to ciphertext that cannot be done to a hash?
Answer & why: (a) Correct: an encrypted password can be decrypted with the key; a one-way salted slow hash cannot be reversed, which is what password storage needs.

8. Using the toy RSA public key (n=33, e=3), encrypt m=5. (5^3 = 125.) MCQ (one answer) L3 · Asymmetric & PKI

Hint: Compute 125 mod 33.
Answer & why: (a) Correct: 125 mod 33 = 125 − 3×33 = 125 − 99 = 26. (b) 125 is before the modulo. (c) 5 is the plaintext. (d) 17 is unrelated.

9. An attacker records a Diffie-Hellman exchange and sees p, g, A and B. Why can they not compute the shared secret? MCQ (one answer) L3 · Asymmetric & PKI

Hint: What hard math problem protects Diffie-Hellman?
Answer & why: (a) Correct: for a large prime, computing the private exponent from g^x mod p is infeasible. The other options are not what protects DH.

10. A browser shows 'your connection is not private' because the certificate's name does not match the site. What failed? MCQ (one answer) L3 · Asymmetric & PKI

Hint: Three checks: trusted chain, matching name, valid date. Which one is this?
Answer & why: (a) Correct: a name mismatch is exactly what a man-in-the-middle presenting its own certificate produces. The other options describe different failures.

11. Which pairing is genuine multi-factor authentication? MCQ (one answer) L4 · Authentication & MFA

Hint: The two proofs must be from different categories (know/have/are).
Answer & why: (a) Correct: inherence + possession. The others combine two knowledge factors.

12. Why does NIST treat SMS one-time codes as the weakest second factor? MCQ (one answer) L4 · Authentication & MFA

Hint: What can an attacker do to a phone number?
Answer & why: (a) Correct: SIM-swap or interception makes SMS 'restricted'. SMS codes do expire; they are a possession factor; length is not the issue.

13. What stops a real-time phishing page from reusing a passkey signature on the genuine site? MCQ (one answer) L4 · Authentication & MFA

Hint: What does the device include in the signature besides the challenge?
Answer & why: (a) Correct: the signature is site-bound and useless on a look-alike page. The server stores only a public key; a passkey is not a shared secret or a 30-second code.

14. In the TLS 1.3 handshake, which step provides forward secrecy? MCQ (one answer) L5 · Key management

Hint: Forward secrecy comes from a key that is new each session and then discarded.
Answer & why: (a) Correct: a fresh ephemeral key per session means a later long-term key theft cannot decrypt past traffic.

15. Why must a cryptographic key come from a CSPRNG rather than the system clock? MCQ (one answer) L5 · Key management

Hint: What property must a key have against an attacker?
Answer & why: (a) Correct: keys must be unpredictable; a clock-derived key can be guessed. The other options are not real reasons.

16. Which statements about classical ciphers are TRUE? (select 3) MSQ (select 3) L1 · Classical ciphers

Hint: Three are true: Caesar's rule, how frequency analysis works, and the one-time pad's guarantee.
Answer & why: True: (a), (b), (d). False: (c) a pad is used once and is as long as the message; (e) Vigenère falls to Kasiski + per-column analysis; (f) Base64 is encoding, not encryption.

17. Which choices make password storage correct? (select 2) MSQ (select 2) L2 · Symmetric & hashing

Hint: The two-part rule: unique salt + slow function.
Answer & why: True: (a) unique salt defeats precomputation; (b) slowness defeats scale. The rest are the classic mistakes.

18. Which statements about cryptographic hashes are TRUE? (select 3) MSQ (select 3) L2 · Symmetric & hashing

Hint: Definition, avalanche effect, and the meaning of a collision.
Answer & why: True: (a), (b), (c). False: (d) both are broken for collisions; (e)/(f) a hash has no key and cannot be reversed.

19. Which statements about public-key cryptography are TRUE? (select 3) MSQ (select 3) L3 · Asymmetric & PKI

Hint: Encryption direction, signing direction, and why TLS is hybrid.
Answer & why: True: (a), (b), (c). False: (d) the keys are different and linked; (e) factoring is HARD; (f) verification uses the public key.

20. For a browser to show the padlock, which conditions must ALL hold? (select 2) MSQ (select 2) L3 · Asymmetric & PKI

Hint: Trusted chain, matching name, valid date.
Answer & why: True: (a) and (b). False: (c) self-signed breaks the chain; (d) ECDHE makes a fresh key, no prior sharing; (e) MD5 is rejected; (f) private keys are never published.

21. Which statements about MFA are TRUE? (select 3) MSQ (select 3) L4 · Authentication & MFA

Hint: Definition, ranking, and the effect on a stolen password.
Answer & why: True: (a), (b), (c). False: (d) both are knowledge; (e) SMS is weakest; (f) biometrics cannot be reset.

22. BlueFern is rolling out MFA. Which decisions follow the guidance? (select 2) MSQ (select 2) L4 · Authentication & MFA

Hint: Strongest factor on the highest-value accounts; app TOTP above SMS.
Answer & why: True: (a) and (b). False: (c)/(f) still knowledge; (d) SMS is weakest; (e) strong passwords still leak and are reused.

23. Which statements about key management are TRUE? (select 3) MSQ (select 3) L5 · Key management

Hint: Rotation, HSM storage, and where real failures come from.
Answer & why: True: (a), (b), (c). False: (d) keys must rotate; (e) never publish a private key; (f) a VPN has its own keys to manage.

24. Which measures satisfy the off-site OR offline backup-of-keys idea / sound key handling for BlueFern? (select 2) MSQ (select 2) L5 · Key management

Hint: Required-VPN-with-MFA and a clear rotation table; reject the four failures.
Answer & why: True: (a) and (b). False: (c) e-mailing a shared secret exposes it; (d) start-up time is predictable; (e) waiting for an outage is the failure automation prevents; (f) never store a private key in a repo.

25. Which are TRUE about the post-quantum transition? (select 2) MSQ (select 2) L5 · Key management

Hint: Symmetric needs bigger keys; public-key is the vulnerable part; 'harvest now, decrypt later' makes it urgent.
Answer & why: True: (a) and (b). False: (c) such machines do not yet exist; (d) hashes need larger outputs, not abandonment; (e) CAs continue with PQC signatures; (f) long-lived secrets are at risk now.
